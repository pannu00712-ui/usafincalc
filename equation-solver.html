What This Equation Solver Does

Enter a linear equation in the form ax + b = c and this tool solves for x, showing each algebraic step used to isolate the variable.

How It Works

To solve ax + b = c for x: first subtract b from both sides to get ax = c − b, then divide both sides by a to get x = (c − b) / a. The same balance principle — whatever you do to one side of an equation, you must do to the other — applies to solving any linear equation.

Checking Your Answer

Once you have a value for x, substitute it back into the original equation. If both sides come out equal, the solution is correct. This is a useful habit for any algebra problem, not just the ones this calculator solves.

Frequently Asked Questions

How do you solve a linear equation for x?

Isolate x by performing inverse operations on both sides of the equation in reverse order of operations — typically undo addition/subtraction first, then undo multiplication/division.

What if the equation has no solution or infinite solutions?

If simplifying leads to a false statement (like 3 = 5), there's no solution. If it leads to a true statement with no variable left (like 4 = 4), every value of x satisfies the equation, meaning infinite solutions.

Can this solve quadratic equations?

This tool solves linear equations (where x appears to the first power only). For equations with an x² term, use the Quadratic Formula Calculator instead.
